# Разговорные формы: анализ

Повод: «нягыл» (не қыл) и «нестимиз» (не істейміз) не исправляются.

## Что проверено

Набор `Tools/TypingTests/colloquial.tsv`: 57 разговорных фраз так, как их пишут в переписке.

| Группа | Пример | Верно |

| Разговорное сокращение гласной | истимин (істеймін), дисин (дейсің) | 0 из 1 |
| Разговорные окончания | жатсың, білем, жатырмын, түсінбедім | 10 из 10 |

| **Всего** | | **40 из 57** |

Не прошли: все 14 «не + глагол», «истимин», «калесин» (қалайсың) и «казыр» (оставлено «қазыр»).
Ещё проверены вне набора и тоже не исправляются: неболды, недейсин, нетесин, нетейин,
нестейин, нагыласын, дисин, сойлимиз, калесиз.

## Почему

Словарь собран из новостей, а там так не пишут. Сколько раз формы встречаются в корпусе
(10,8 млн слов) и в казахских субтитрах:

| Форма | Новости | Субтитры |
|---|---|---|
| неғыл / нағыл / няғыл | 3 / 1 / 0 | 0 |
| нестейміз, нестиміз, нетеміз, нестедің | 0 | 0 |
| неғып | 48 | 1 |
| боп / қып / кеп | 2532 / 153 / 483 | 8 / 0 / 2 |
| жатам / жатсың | 10 / 9 | 0 / 1 |
| қалесің | 0 | 0 |

То, что есть в корпусе, исправляется: «негыл» → «неғыл», «негып» → «неғып». Но это уже
вопрос, как писать результат (ниже).

## Какие бывают формы

1. **«Не» + глагол слитно.** Это одна из самых частых форм в чате, и у неё много вариантов:
   - қыл: нягыл, неғыл, нағыл, неғылайын, нағыласың, неғылдың; с -ып: неғып, нағып (не қып);
   - істе: неістейсің, нестейсің, нестейміз, нестиміз, нестедің, нестеп, нестейін;
   - ет: нетеміз, нетесің, нетейін, нетіп;
   - другие: неболды (не болды), недейсің (не дейсің).

   Это правило, а не список. Берём начало (негыл/нағыл/нягыл, нест/неіст, нет) и проверяем,
   что остаток — настоящее окончание этого глагола из корпуса (қыл-айын, істе-йміз, ет-еміз).
   Тогда русские слова на «нет-», «нест-», «неист-» (301 слово: нетерпение, нестандартный,
   неистовый…) не задеваются. К тому же слова из русского списка не меняются вообще.
2. **Сокращение «-ей-/-ай-» → «-и-».** «Істимін» вместо «істеймін», «дисің» (дейсің),
   «сөйлиміз» (сөйлейміз). Правило: если слова нет, пробуем «и» → «ей/ай» перед окончаниями
   -мін/-міз/-сің/-сіз и берём вариант, который есть в корпусе.
3. **Разговорные приветствия и обороты.** «Қалесің», «қалесіз» (қалайсың, қалайсыз) и подобные.
   Их немного, нужен короткий ручной список.
4. **Уже работает:** разговорные окончания (жатсың, білем, жатам), сокращённые деепричастия
   (боп, қып, кеп, сап), частицы (ғой, ба), большинство чатовых слов.

## Что писать в результате

Нужно решить:

- **Стандартно:** «нягыл» → «не қыл», «нестимиз» → «не істейміз», «қалесің» → «қалайсың».
  Так же, как уже сделано для «айтасынба» → «айтасың ба» и «го» → «ғой».
- **Как сказано, только с казахскими буквами:** «нягыл» → «няғыл», «нестимиз» → «нестіміз».

Рекомендация: «не + глагол» и «-и-» вместо «-ей-» писать стандартно, а разговорные окончания
и деепричастия (жатсың, боп, қып) оставлять как набраны. Они привычны в переписке и не мешают
читать.

## Данные

Новостей мало для разговорной речи. Подходит **KazSAnDRA**: 180 064 отзыва из App Store,
магазинов, карт и книжного, неформальный казахский, часто набранный русскими буквами.
Лицензия CC BY 4.0, [GitHub IS2AI/KazSAnDRA](https://github.com/IS2AI/KazSAnDRA),
[статья](https://aclanthology.org/2024.lrec-main.844). Нужны 3 файла (все отзывы без
дублей): `01_pc_train_ib.zip` 6,9 МБ, `04_pc_valid.zip` 0,9 МБ, `05_pc_test.zip` 0,9 МБ,
**всего ≈ 8,7 МБ**.

Что даст:
- какие разговорные формы реально пишут и как часто, чтобы найти то, чего нет в списке выше;
- набор проверки из живого текста, а не придуманного;
- частые разговорные слова в словарь.

## План

1. Правило «не + глагол» (п. 1) по окончаниям глаголов из корпуса.
2. Правило «-и-» → «-ей-/-ай-» (п. 2).
3. Короткий список разговорных оборотов (п. 3).
4. Скачать KazSAnDRA: найти частые разговорные формы, добавить их в словарь, отложить
   часть отзывов для проверки.
5. Тесты: `colloquial.tsv` и новый набор из отзывов. Русские наборы должны остаться без изменений.

## Что сделано

Решение: «не + глагол» и «-и-» пишутся стандартно, разговорные окончания остаются.

- **Разговорные формы выводит сборщик словаря.** Для «не» + қыл/істе/ет/бол/де он берёт
  стандартные формы глагола и строит то, как их говорят: нағыл/неғыл/няғыл/неқыл,
  нестейміз/нестиміз/неістейміз, нетеміз, неболды, недейсің. Для «-ей-» строит «-и-» и «-еи-»:
  білмимін, білмеимін. Всего 1 880 написаний, флаг `s` в `dictionary.tsv`. Написание не
  берётся, если это настоящее другое слово («нақыл», «неткен», «жемісін») или русское слово
  («нету»). Русские слова на «нет-/нест-/неист-» не задеваются.
- **Слитное «неғып/нағып/няғып» — это «почему»:** пишется «неге» («нягып олай жасадың» →
  «неге олай жасадың»). Раздельное «не қып» («не қып жүрсің») остаётся.
- **Разговорные глаголы «үйт-», «бүйт-», «сүйт-», «өйт-»** (так сделать): в новостях их почти
  нет («үйттің» ни разу), поэтому сборщик добавляет их основные формы как разговорные слова:
  үйттің, үйтпе, бүйтіп, сүйтсем, үйткені…
- **Ручной список** `Tools/kazakh-spoken.txt`: қалесің → қалайсың и подобные.
- **KazSAnDRA** (обучающая и проверочная части). Из отзывов берутся только слова, которых
  нет в новостях, и только из отзывов, написанных с казахскими буквами. Слитные частицы
  («жоқпа») пропускаются. Первая попытка брать всё подряд испортила частые слова
  (болсын → болсың, Каспи → Кәспи, брак → брақ): опечаток в отзывах много. В словарь
  орфографии macOS слова из отзывов не идут.
- **«Твой» против «его»:** «ойын» (игра) превращалось в «ойың» (твоя мысль), 277 раз на 3000
  отзывов. Теперь форма с «-ын» остаётся, если в корпусе есть её множественное число
  («ойындар»): у притяжательной формы его не бывает. Порог 1% не менялся, он нужен для
  переписки («өзің», «күнің»).
