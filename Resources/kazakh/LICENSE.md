# Данные автозамены / Autocorrect data

Файлы в этой папке (`dictionary.tsv`, `context.tsv`, `pairs.tsv`, `endings.tsv`, `russian.txt`,
`kk.dic`, `kk.aff`) собраны скриптом `Tools/make-kazakh-dictionary.py` из открытых корпусов и
распространяются по лицензии
[Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/).

The files in this folder are built by `Tools/make-kazakh-dictionary.py` from the open corpora
below and are licensed under CC BY-SA 4.0.

## Источники / Sources

- **Leipzig Corpora Collection**, `kaz_newscrawl_2016_1M` (казахские новости, 1 млн предложений),
  CC BY. D. Goldhahn, T. Eckart, U. Quasthoff. *Building Large Monolingual Dictionaries at the
  Leipzig Corpora Collection: From 100 to 200 Languages.* LREC 2012.
  <https://wortschatz.uni-leipzig.de/en/download>
- **FrequencyWords** by Hermit Dave: частотные списки `ru_full` и `kk_full` по субтитрам
  OpenSubtitles, CC BY-SA 4.0. <https://github.com/hermitdave/FrequencyWords>
- **KazSAnDRA** (Kazakh Sentiment Analysis Dataset of Reviews and Attitudes), R. Yeshpanov,
  H. A. Varol, ISSAI, LREC-COLING 2024: неформальные отзывы, CC BY 4.0.
  <https://github.com/IS2AI/KazSAnDRA>
- Ручные списки из `Tools/` (разговорные слова, устойчивые фразы, слитные слова, русские слова
  Казахстана, разговорные формы): авторы этого проекта.
